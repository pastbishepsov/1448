## Принципы (не обсуждаются внутри спринтов)

1. **Один файл** `web/admin.html`, ванильный JS, без сборки — как shell.html.
   React-скелет `admin/` не трогаем (после пилота решим: удалить или возродить).
2. **Язык Noir**: чёрная база, красный `#ff2740` — единственный акцент,
   волосяные линии `rgba(255,255,255,.07)`, стекло без рамок.
   **Без FX-шоу** (tilt, конфетти, shimmer) — админке нужны плотность и скорость.
   Семантические цвета статусов остаются: зелёный/оранжевый/красный/серый.
3. **Иконки** — Phosphor duotone, второй тон `#ff2740` (механика `data-ic` +
   `mountIcons()` переносится из shell.html). Эмодзи уходят отовсюду, кроме тостов.
4. **Частота = близость**: чем чаще действие, тем меньше кликов до него.
   Иерархия задач админа: зал → деньги → гость → брони → каталог → журнал → owner.
5. **Никаких `prompt()`/`confirm()`**: формы — в правом drawer, опасные
   действия — красная кнопка с повторным нажатием (arm → confirm), тост с undo
   где отмена безопасна.
6. **Адаптив с каркаса**: строим под десктоп за стойкой, но сетки — flex/grid,
   на узком экране rail сжимается в иконки, таблицы схлопываются в карточки.
   Полная мобильная полировка — А7.
7. Цифры — `font-variant-numeric: tabular-nums`. Время — «1ч 20м», деньги — zł.
8. Каждое действие админа со временем попадает в журнал (полный аудит — А4).

## Планировка (информационная архитектура)

### Каркас

```
┌──────────────────────────────────────────────────────────┐
│ топбар: лого 14:48 ADMIN · поиск «/» · live-точка · кто   │
├──────────┬────────────────────────────────┬──────────────┤
│ rail     │ контент раздела                │ drawer       │
│ Зал      │                                │ (по клику:   │
│ Гости    │                                │ ПК / гость / │
│ Брони ⑥  │                                │ форма)       │
│ Каталог  │                                │ Esc = закрыть│
│ Журнал   │                                │              │
│ ─────    │                                │              │
│ Статист. │  (owner)                       │              │
│ Настройки│  (owner)                       │              │
│ ─────    │                                │              │
│ админ ⏻  │                                │              │
└──────────┴────────────────────────────────┴──────────────┘
```

- **Левый rail** вместо верхних табов: 5 рабочих разделов + 2 owner-раздела
  за волосяным разделителем; внизу — имя и выход. Бэйдж на «Брони» — число
  броней сегодня. На узком экране rail сжимается до иконок (56px).
- **Топбар**: лого (пульс двоеточия — единственный FX, наш знак), глобальный
  поиск по хоткею `/` (ищет гостя/ПК, ведёт в раздел), индикатор
  «live · обновлено N с назад», имя · роль.
- **Правый drawer** — все детали и формы. Таблицы никогда не ведут на
  отдельные «страницы» и не открывают модалок поверх всего.
- **Тосты** снизу по центру; у отмены брони и разбана — кнопка «Вернуть».
- **Хоткеи**: `1–7` разделы, `/` поиск, `Esc` закрыть drawer/форму.

### Разделы — что где и почему

| # | Раздел | Что внутри | Главные действия |
|---|--------|-----------|------------------|
| 1 | **Зал** (дефолт) | KPI-строка + карта ПК по зонам. Плитка ПК: имя, статус цветом, ник гостя + таймер сессии; «скоро бронь» — глиф часов. Заменяет обе старые вкладки «ПК» и «Сессии» — это один и тот же вопрос «кто где сидит» | drawer ПК: завершить сессию (arm-confirm, показывает что начислится), в ремонт / из ремонта, инфо Shell (online, agent) |
| 2 | **Гости** | Живой поиск (debounce 300мс, без потери фокуса), таблица: ник · LVL · монеты · статус · был активен. Быстрое действие прямо в строке — одно: «Депозит» (самое частое) | drawer гостя: профиль (LVL, XP, ранг, монеты, кейсы) + мини-вкладки Сессии / Депозиты / Начисления; действия: депозит (сумма + метод cash/card/blik), +XP (сумма+причина), кейс (тир кнопками), бан (arm-confirm) / разбан |
| 3 | **Брони** | Фильтр: сегодня / завтра / все + по статусу. Таблица: когда · гость · ПК · длительность · предоплата · статус | отменить (с undo-тостом); создать walk-in бронь за гостя (форма в drawer) |
| 4 | **Каталог** | Таблица как сейчас: id · название · категория · target · вкл | drawer-форма вместо инлайновой; тумблер вкл/выкл; порядок стрелками ↑↓ (drag — опция позже); предпросмотр плитки 2:3 как на гостевом экране |
| 5 | **Журнал** | Единая лента всех действий: гранты, депозиты, баны, форс-энды, отмены броней. Фильтры: тип / админ / гость | только чтение |
| 6 | **Статистика** (owner) | Выручка сегодня/неделя, спарклайн 14 дней, загрузка по часам, топ гостей по часам/депозитам | переход в карточку гостя |
| 7 | **Настройки** (owner) | Экономика: XP/мин, coins/мин, курс zł→монеты, тарифы зон; адрес API | сохранить (сейчас значения захардкожены в бэкенде — см. А5) |
