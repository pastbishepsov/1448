# 14:48 — Мобилка: трек М (гостевое PWA)

> Точка входа для работ по мобильному приложению гостя. Трек М родился
> 2026-07-18: Flutter-скелет `mobile/` признан заглушкой (один экран-логотип,
> старый красный #D90025, пустые screens/services/widgets) — вместо него
> делаем PWA в языке клубного экрана.
> Контекст: STATUS.md, DESIGN.md («14:48 Noir»), ADMIN.md (решение №8 — поллинг).
> Правило то же: не начинаем следующий спринт, пока текущий не закрыт.
> **Критерий закрытия: работает с реального телефона (iPhone Safari +

## Продуктовые решения (зафиксированы 2026-07-18, внутри спринтов не обсуждаются)

1. **Платформа v1 — PWA одним файлом `web/app.html`** + два спутника
   (`web/app.webmanifest`, `web/sw.js` — только ради установки на главный
   экран). Никаких фреймворков: ванильный JS/CSS, как shell.html и admin.html.
   Flutter `mobile/` замораживается до решения о сторах после пилота
   (не удалять). Обёртка в сторы (TWA/Capacitor) — бэклог, на этот же код.
2. **Дизайн = клубный экран.** Токены `:root` копируются из `web/shell.html`
   1-в-1 (`--bg #070708`, `--acc #ff2740` — единственный акцент, glass,
   волосяные линии, `--t-*` тиры, spring-кривые). При расхождении истина —
   shell.html. Иконки — та же трёхслойная система (Simple Icons / Phosphor
   duotone со вторым тоном `--acc` / game-icons) через `data-ic` +
   `mountIcons()`. Правило цифр действует (всё видимое кратно 5, пороги — 100).
3. **Один аккаунт везде.** Вход как в клубе: ник + пароль, JWT
   access/refresh с ротацией — `api()`, `tokens()`, ключи `1448_access` /
   `1448_refresh` / `1448_api` переносятся из shell.html как есть.
   OTP по SMS — только после Twilio (спринт 6), строки в UI не показываем.
4. **Никакого WS на телефоне — поллинг** (решение №8 ADMIN.md
   распространяется на мобилку): `/me/sessions` 10с (только при открытой
   главной и активной сессии), `/clubs` 15с, `/me/chat` + `/me/notifications`
   12с. При `visibilitychange` → hidden поллинг останавливается.
5. **Навигация — 4 вкладки снизу:** Клуб · Кейсы · Прогресс · Чат.
   Топбар с XP-баром виден всегда. Бэйджи: непрочитанное на «Чате»,
   неоткрытые кейсы на «Кейсах». Свайпы — только как дублёр, не
   единственный путь.
6. **FX на таче — облегчённый набор.** Без 3D-tilt/spotlight/magnet (нет
   ховера). Остаются: конфетти дропа/левел-апа, count-up чисел, пульс
   двоеточия, press-scale, ripple вместо click-spark. Перф-гарды как в
   shell (`prefers-reduced-motion`, слабое железо → perf-lite).
7. **Тач-гигиена:** цели касания ≥44px, `font-size` инпутов ≥16px (иначе
   iOS зумит), `safe-area-inset-*` (вырезы), один столбец, tabular-nums
   в числах. Никаких `prompt()`/`confirm()` — шторки и arm-confirm.
8. **v1 одноклубный:** берём первый клуб из `GET /clubs` (как admin).
   Мультиклуб и карта (Google Maps) — бэклог.
9. **Язык v1 — русский** (как клубный экран), но все строки сразу в одном
   словаре `STR` — готовность к EN/PL к пилоту (жёсткие правила проекта).
10. **Серверные правки минимальные [go]:** раздача статики `/app` +
    манифест + SW + иконки. CORS не нужен — same-origin. Новых таблиц нет,
    все эндпоинты уже существуют.
11. **shell.html меняем только в зоне связки** (QR-блок в М5), остальное
    гостевое не трогаем. Правки app.html — по тем же правилам верификации,
    что shell.html (эталон из `git show HEAD:`, node-скрипты, проверка
    хвоста `</html>`).

## Планировка

```
┌────────────────────────────────┐
│ топбар: 14:48 · ава ник        │
│         LVL·ранг · монеты      │
│ ▓▓▓▓▓▓▓▓░░░░ XP-бар            │
├────────────────────────────────┤
│                                │
│   контент вкладки              │
│                                │
│   Клуб: свободно N из M        │
│   [Забронировать место]        │
│   live-карточка сессии         │
│   мои брони                    │
│                                │
├────────────────────────────────┤
│  ⌂ Клуб · ▣ Кейсы(2) ·         │
│  ↗ Прогресс · ✉ Чат(1)         │
└────────────────────────────────┘
```

- **Клуб** (главная): «Свободно N из M» + адрес/часы, кнопка брони,
  live-карточка сессии, когда играешь (таймер, +XP), мои брони с отменой.
- **Кейсы:** список с тирами и таймерами сгорания, полноэкранное открытие.
- **Прогресс:** XP/уровень/ранг, таланты, ачивки, лидерборд, история
  сессий и пополнений, баланс.
- **Чат:** тред с админом, уведомления-центр; тосты — глобально.

## Спринты

Бэкенд-работы — **[go]**. Миграции не нужны (нумерация стоит на 021).

### М0 — Каркас и вход
- [ ] и1: `web/app.html`: meta viewport/theme-color `#070708`, токены
      `:root` из shell.html, фирменный красно-чёрный фон (blob'ы),
      системный шрифт; каркас топбар + нижняя навигация (Phosphor duotone,
      активная — красная) + 4 пустые вкладки;
- [ ] и2: перенос `api()` / `tokens()` / refresh-ротации из shell.html;
      экран входа = authView shell (Вход/Регистрация, ник+пароль, лого с
      пульсом двоеточия, слоган);
- [ ] и3: топбар живой: ава+ник, LVL·ранг, XP-бар со свечением, монеты
      (`GET /me`), count-up при изменении;
- [ ] и4: **[go]** раздача статики: `GET /app` → `web/app.html`,
      `/app.webmanifest`, `/sw.js`, `web/icons/` (192/512 из лого);
      SW минимальный: network-first, офлайн-экран «нет сети»;
- [ ] и5: пометка в `mobile/README.md`: Flutter заморожен до после пилота,
      активный трек — MOBILE.md (PWA).
- Критерий: с телефона по Wi-Fi открыл `http://<ip>:8080/app`,
  зарегистрировался, увидел свои XP/монеты, поставил на главный экран.

### М1 — Клуб и брони
- [ ] и1: главная: карточка клуба (`GET /clubs`) — «Свободно N из M»,
      обновление 15с; пустые состояния и скелетоны;
- [ ] и2: бронь: чипы «сегодня/завтра», пикер времени шагом 30 мин +
      длительность, `POST /clubs/:id/bookings`; ошибка пересечения —
      по-человечески («это время занято, ближайшее свободное — …»);
- [ ] и3: мои брони (`GET /me/bookings`): ближайшая — крупно, отмена с
      undo-тостом (`DELETE`, восстановление повторной броней);
- [ ] и4: live-карточка сессии на главной (поллинг `/me/sessions` 10с):
      таймер, +XP за сессию count-up, зелёный tint как в сайдбаре shell.
- [ ] и5: вейтлист из кармана (Б9 «задел PWA»; добавлен 2026-07-23): при
      «свободно 0» — «Встать в очередь» (`POST /me/waitlist`), позиция
      «ты N-й из M» (поллинг 15с вместе с /clubs), выход из очереди;
      по notified — подсветка «ПК освободился — подойди к стойке».

### М2 — Прогресс
- [ ] и1: вкладка «Прогресс»: XP-бар до следующего уровня, ранг с лаврами
      (game-icons) и шкалой часов до следующего, стата (часы, сессии);
- [ ] и2: таланты: 3 ветки, вложение очка с arm-confirm, эффекты словами
      («+12% XP»), бэйдж свободных очков;
- [ ] и3: ачивки (получено/доступно) + лидерборд (топ + твоё место,
      `.lvlpill`);
- [ ] и4: история сессий и пополнений — волосяные разделители,
      tabular-nums, баланс монет крупно.

### М3 — Кейсы
- [ ] и1: список кейсов: глифы-сундуки тиров по красной шкале (`--t-*`),
      star-border на Titan/God's, таймер «сгорит через N дн», бэйдж
      unopened на вкладке;
- [ ] и2: открытие: полноэкранный оверлей с саспенсом → дроп, конфетти
      (красно-белые), count-up выигрыша; повторное открытие — без
      перезагрузки списка;
- [ ] и3: перенос облегчённого FX-движка из shell (конфетти, count-up,

### М4 — Деньги и связь
- [ ] и1: баланс и пополнения: история (`GET /me/deposits`), курс и ставки

- [ ] и2: уведомления: поллинг `/me/notifications` 12с → тосты (отмена/

- [ ] и3: чат с админом: тред (`GET/POST /me/chat`), бэйдж непрочитанных

### М5 — Установка и полировка
- [ ] и1: PWA-паспорт: standalone, иконки, splash-цвета, safe-area на

- [ ] и2: QR «клуб в кармане» на гостевом экране (shell.html, зона связки:
      блок в профиль-оверлее со ссылкой на `/app`);
- [ ] и3: аудит: словарь `STR` всех строк (задел под EN/PL), правило цифр,
      пустые состояния всех вкладок, офлайн-экран;
- [ ] и4: прогон на iPhone Safari + Android Chrome: установка, вход,
      бронь, кейс, чат — чек-лист руками.
