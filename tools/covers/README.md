# Обложки игр (web/covers/)

`fetch-covers.ps1` скачивает вертикальные постеры 600×900 в `web/covers/{id}.jpg`.
Киоск офлайн — файлы должны лежать локально и быть закоммичены.

- **Steam-игры** (cs2, dota2, gta5, apex, pubg, rivals, ow2) — официальные
  капсулы библиотеки с публичного CDN Valve, ключ не нужен.
- **Вне Steam** (valorant, lol, fortnite) — SteamGridDB по API-ключу
  (`-SgdbKey`, бесплатно: steamgriddb.com → Preferences → API), либо положить
  свои файлы 600×900 вручную.

Плитка подхватывает обложку автоматически: набор `COVERS` в `web/shell.html`
перечисляет id с файлами. Добавил игру → добавь id в `COVERS` и файл в covers/.
Нет файла — плитка честно показывает TAG-fallback (градиент + типографика).

## Права

Обложки — маркетинговые материалы издателей. Показ в лаунчере клуба для
запуска установленных игр — общепринятая индустрией практика (так делают
ggLeap, Langame и др.), но формально это ИС издателей: используем только для
установленных в клубе игр, не для рекламы вовне. Ассеты со SteamGridDB —
фанатские работы (автор пишется в конце строки при скачивании); при желании
атрибуцию можно добавить на экран «инфо». Это примечание — не юридическая
консультация.
