## 1. В текущие спринты М1–М5 (мобилка) — брать сейчас

- **View Transitions для переключения вкладок** — Baseline с окт 2025
  (Chrome 111+, iOS 18+, Firefox 144). Одна строка feature-detect:
  `document.startViewTransition ? startViewTransition(swap) : swap()`.
  Деградация — мгновенное переключение, как сейчас. [caniuse](https://caniuse.com/view-transitions)
- **`@starting-style` + `transition-behavior: allow-discrete`** — честная
  CSS-анимация появления/ухода шторок и тостов из `display:none`, без
  JS-таймеров и классов-«маркеров». Chromium 117+, iOS 17.4+.
- **Установка на iOS: инструкция упрощается.** iOS 26 (сен 2025): «zero
  requirements for installability» — любой сайт со значка открывается как
  web app; манифест остаётся ради иконки/имени/цветов. В М5 инструкция
  «Поделиться → На экран Домой» покрывает всех. [webkit.org](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/)
- **Манифест в М5 дополнить `screenshots` + `description`** — Android Chrome
  показывает Richer Install UI (диалог со скриншотами вместо серой плашки).
- **Хаптика в кейсах (М3): только Android.** `navigator.vibrate()` на тики
  рулетки и дроп — дёшево и тактильно; на iOS Vibration API нет во всех
  версиях вплоть до 26.x — не тратить время (существует хак через
  `<input type="checkbox" switch>`, iOS 18+ — опционально, за настройкой).
- **`field-sizing: content` для инпута чата (М4)** — автогроу без JS.
  Chromium 123+, iOS только с 26.2 — ставить как enhancement.
- **Канон кейс-опенинга** (сверить М3): горизонтальный реел под фиксированным
  маркером, «разгон → долгое торможение → микро-докат», редкость = цвет
  рамки/свечения, отдельный экран приза, только transform/opacity.
  Наш ход: **красный #ff2740 отдать top-tier дропу** — акцент бренда =
  максимальная редкость.
- **Слепой version-check поверх SW** — iOS агрессивно кэширует сам sw.js и
  не обновляет его в фоне; гость может залипнуть на старой версии. Рецепт:
  при старте сравнивать версию из `/health` или meta с зашитой, при
  расхождении — `registration.update()` + одноразовый reload. Workbox не
  нужен (жив, v7.4.1, но для нашего одностраничника избыточен).

## 2. Пуши и real-time (бэклог М6+, разблокируется HTTPS)

- **Web Push на iOS работает** (с 16.4), но только для PWA с домашнего
  экрана, permission строго из клика, и каждый push обязан показать
  уведомление через `showNotification()` — иначе «silent push penalty» и
  iOS отзывает подписку. Подписки умирают от неактивности → чистить по
  410/404 и держать фолбэк (тосты в приложении уже есть — Б4).
- **Declarative Web Push** — iOS 18.4+ (к 2026 покрывает актуальные
  айфоны): JSON-пейлоад, ОС показывает уведомление сама, SW не нужен —
  надёжнее на iOS. Chromium пока не реализовал → слать один декларативный
  формат, Android обработает классическим SW-путём. Сервер: жива
  [webpush-go](https://github.com/SherClockHolmes/webpush-go) (VAPID, протокол заморожен годами), таблица подписок =
  миграция 022. [webkit.org](https://webkit.org/blog/16535/meet-declarative-web-push/)
- **Ради чего пуши**: «бронь через 30 мин», «твой ПК освободился»,
  «кейс сгорит завтра», «твой рекорд в лидерборде побили» (паттерн
  Multitap — возврат гостя без маркетолога). Это retention-механика, не
  просто уведомления.
- **Поллинг → SSE после пилота** — консенсус 2026: SSE для однонаправленных
  статусов (брони/баланс/чат-инбокс), WS только для двунаправленности.
  В Go SSE нативен (Flusher, без либ), `EventSource` сам реконнектится,
  `Last-Event-ID` дозагружает пропущенное; за Caddy c HTTP/2 лимит
  6 соединений исчезает. Поллинг-код не выбрасывать — остаётся fallback'ом
  (мобильные ОС всё равно рвут соединения в фоне). Решение №8 (WS гостю не
  нужен) миром подтверждено.

## 3. Идеи из индустрии (кандидаты в Б9+ / М6+ / спринт 6)

Источники: фичесеты и changelog'и ggLeap, Senet (SENET ID), iCafeCloud,
Langame (LANGAME+, июль 2026), Gizmo + местный конкурент BaseStack (Łódź).

- **QR-вход за ПК с телефона** — скан QR с лок-скрина → сессия стартует,
  телефон = ключ. Топ-паттерн 2026 у всех лидеров (SENET ID, iCafeApp
  «логин+включение одним сканом»). У нас всё готово: лок-скрин киоска,
  app.html, `startSessionFor`. Киллер-фича для М6.
- **Предоплата брони + no-show-таймер** (ggLeap): бронь оплачивается через
  Stripe, не пришёл за N минут — ПК автоматически освобождается. Плюс
  правила «за сколько минут можно бронировать» и исключение отдельных ПК
  из онлайн-брони. Ложится ровно в спринт 6 (Stripe+BLIK); заодно оживит
  талант `priority_booking`.
- **Пассы / пакеты часов / комбо** — сильнейший пробел монетизации:
  BaseStack продаёт Play Packs «часы+еда» от 32 zł и дей-пассы 100–140 zł,
  ggLeap в июне 2026 выкатил Combo Deals (время+еда+услуги одним SKU),
  Senet — абонементы с историей. У нас есть каталог и кошелёк — нет
  пакетов. Кандидат в экономику после пилота.
- **Заказ еды с ПК и из PWA со статусом** (Senet Shop-in-Shell, iCafeApp
  «готовится → несут»): каталог на киоске уже есть — добавить корзину,
  статус заказа и тост гостю; в админке — очередь заказов (у нас уже есть
  live-лента и чат — инфраструктура готова).
- **Очередь-вейтлист, когда всё занято** (ggLeap dashboard widget) —
  «встать в очередь» в PWA + виджет очереди в Зале админки.
- **Динамические цены по часам** — happy hours/утренние тарифы у Senet и
  ggLeap. У нас уже есть ночная скидка (`night_mode`) — обобщить в
  настройках owner до тарифной сетки по часам/дням.
- **Авто-отчёт смены в Telegram владельцу** (Langame) — дёшево: сводка дня
  (выручка/депозиты/сессии/инциденты) ботом в конце смены.
- **Сегменты гостей: новые / вернувшиеся / пропавшие** (Langame) — в
  «Деньги» owner'а; основа для будущих win-back пушей.
- **Промо-монеты отдельно от депозитных** (Senet «двойной баланс») — чистит
  и юридику (см. §4), и экономику (кэшбек/подарки ≠ внесённые деньги).
  Усложнение — взвесить до пилота.
- **«Сейчас в клубе играют в …»** (lanager) — соц-слой на экраны клуба и в
  PWA; у агента уже есть heartbeat, знаем запущенное из allowlist.
- **Недельный срез лидерборда** — лиги ~30 человек у Duolingo работают
  из-за достижимости; клубный аналог — недельный топ зала (наш лидерборд
  сейчас all-time, вечные топы демотивируют новичков).
- **Стрики делать мягкими** — данные Duolingo: streak freeze поднимает
  удержание стрика на ~48% → фриз за монеты вместо потери всего; PEGI
  с 2026 маркирует «жёсткие» дейлики со штрафами как риск-категорию.
  У нас стрики в ачивках «ждут механик» — вот рамка для них.
- **Валидация курса**: True Gamers с «только бронь+кошелёк» имеет 3.6★ —
  гостям этого мало; ggLeap продаёт геймификацию (коины/ачивки/лидерборды)
  как премиум. Наша ставка кейсы+таланты+ранги+сенса-студия — глубже, чем
  у коробочных; сенса-студии нет ни у кого из лидеров.
- **Рынок площадок** дрейфует в гибрид: консоли/симрейсинг/VR-зоны,
  TCG-вечера, буткемпы, дневной коворкинг, мемберства $100–150/мес — это
  продуктовые опции клуба (не софта), но схема зала и брони должны уметь
  «не-ПК места» (у нас тип устройства в схеме зала — задел есть).

## 5. Go, сервер, инфраструктура

- **Апгрейд Go до 1.25.x (или 1.26.x)** — поддерживаются только два
  последних мажора: 1.26 (фев 2026) и 1.25; на 1.22–1.23 security-фиксы
  уже не приходят. Цена: bump в go.mod + пересборка, совместимость
  практически гарантирована. Бонусы 1.25: container-aware GOMAXPROCS (наш
  docker compose), `testing/synctest` (тесты броней/таймеров с виртуальным
  временем — flaky-sleep'ы исчезают), `http.CrossOriginProtection`
  (CSRF-защита одной обёрткой — пригодится к выходу в интернет),
  `sync.WaitGroup.Go`. 1.26: GreenTea GC по умолчанию (−10–40% GC-оверхеда
  даром). `encoding/json/v2` — всё ещё эксперимент, не включать. [go.dev](https://go.dev/doc/devel/release)
- **Gin + GORM оставляем** — GORM жив (generics API с v1.30 опционален;
  брать v1.31.2+, в v1.31.1 ломался Preload), хайп sqlc/pgx к нагрузке
  «десятки ПК» нерелевантен. Голый `net/http` ServeMux с 1.22 покрыл бы
  наш REST — знать, но Gin выпиливать незачем.
- **Postgres**: не срочно; при пересоздании стека — сразу PG18 (`uuidv7()`,
  асинхронный I/O, лёгкие будущие pg_upgrade). PG13 уже EOL.
- **HTTPS — рецепт для спринта 6** (это блокер PWA-install и пушей):
  дешёвый домен → **Caddy** перед бинарником (авто-TLS, wildcard через
  DNS-01 — работает даже без открытых портов) → в роутере клуба
  **split-DNS**: `club.domain.pl` → LAN-IP сервера; снаружи тот же домен →
  VPS/белый IP. Один валидный сертификат и в LAN, и снаружи; SSE поверх
  HTTP/2; WS проксируется прозрачно. Альтернатива без Caddy — certmagic
  прямо в Go-бинарнике (сохраняет single binary). Cloudflare Tunnel гонит
  клубный LAN-трафик через интернет — годится только как внешний вход;
  Tailscale Funnel — для удалённого доступа админа, не для гостей.
- **WebView2 / киоск**: Worker APIs стабильны (июнь 2026);
  `PermissionKind.PersistentStorage` — защитить кэш киоска от вытеснения;
  Enhanced Security Mode (отключение JIT) — присмотреться для
  необслуживаемого киоска; **Widevine DRM в WebView2 по-прежнему нет** —
  защищённые стриминги в киоске не заработают. Сентябрьские KB 2025 ломали
  kiosk-конфигурации Windows 11 → на игровых ПК держать **отложенное
  кольцо обновлений** + смоук-тест киоска после патчей. На горизонте
  Local Network Access в Chromium (permission на запросы к LAN-IP с
  публичных origin) — схема split-DNS same-origin нас обходит стороной,
  но помнить при экспериментах.
- **Screen Wake Lock** (Chromium 84+, iOS 16.4+) — одна строка, если
  какой-то экран (attract/витрина) не должен гаснуть.

## 6. Дизайн: Noir против трендов 2026

- **Мы в тренде, ревизия не нужна**: elevated dark поверхности + один
  акцент + duotone-иконки + сдержанный глоу — ровно рецепт 2026. Полный
  Liquid Glass в веб не тащить (Chromium-only фильтры, перф, читаемость —
  Apple сама дважды откручивала прозрачность назад); наш glass-лайт на
  оверлеях — уже правильная доза.
- **Phosphor остаётся** — v2.1.x, 7000+ иконок, duotone по-прежнему наш
  различитель (Lucide «у всех», Tabler без duotone). Недостающие
  киберспорт-глифы — свои SVG в том же стиле (как уже сделали с
  apex/ow2/rivals).
- **Контраст**: #ff2740 на почти-чёрном ≈ 5.4:1 — AA проходит; прогнать
  серые ступени текста и красный мелким кеглем (APCA — не стандарт и не
  закон, юридическая база — WCAG 2.x).
- **Админке в Б9+**: command palette (Ctrl+K) поверх нашего «/»-поиска —
  объединить навигацию + действия («посадить гостя», «новая бронь») с
  recent items; density-переключатель таблиц (Журнал/Деньги:
  comfortable/compact); celebration-микроанимация на закрытие смены.
- **Шрифты — по желанию, боли нет**: если захочется фирменности — пара
  «дисплейный + текстовый» с кириллицей и latin-ext (польский):
  Unbounded (техно-дисплей, для цифр/заголовков киоска) + Onest или
  Golos Text (плотные таблицы). Системный шрифт в PWA — легитимный выбор.
- **OLED / attract-режим киоска** — idle-экран на чистом #000 (лого, пульс
  двоеточия, «свободно N из M», ближайшие брони) — витрина клуба + меньше
  выгорания панелей. Дёшево поверх лок-скрина.

## 7. Что сознательно не трогаем (сверено с 2026)

Single-file vanilla (валидно, ggLeap-прецедент) · поллинг как база v1 ·
Gin+GORM · WS-хаб админки (двунаправленность оправдана) · Phosphor duotone ·
палитра Noir · Flutter в заморозке (правильно: PWA-путь подтверждён) ·
Workbox не нужен · `encoding/json/v2` не включать · Postgres-мажор не
срочен · сторонний роутер не выпиливать · WebTransport — «через год-два»,
хотя Safari 26.4 его наконец поддержал.
