# Разведка: инвентарь игр пилотного клуба (данные для каталога)

Машинная выгрузка с ПК **PC102** (дамп 31.08.2026, `libraryfolders.vdf` +
35 `appmanifest_*.acf` + ярлыки + командные строки процессов). Источник правды
для наполнения каталога 14:48. Контекст — `docs/РАЗВЕДКА-РЕЗУЛЬТАТ.md`.

## Главное для каталога

- Игры лежат **локально** на диске `D:` (6.6 ТБ «Games», занято ~1.5 ТБ).
  Сетевая шара `\\192.168.123.97\share` (Z:) — отсоединена, это мастер
  обновлений, НЕ путь запуска.
- Почти всё стоит под общим корнем **`D:\online\`** → это и есть кандидат в
  настройку клуба **`games_root` = `D:\online`**, а `target` писать как
  `{GAMES}\Battle.net\Battle.net Launcher.exe`.
- Исключения вне `D:\online`: CS 1.6 (`C:\Gry\…`), WolfTeam (`C:\Game\…`),
  EA app (`C:\Program Files\…`) — им абсолютный путь без `{GAMES}`.
- Steam-играм путь не нужен: `target` = `steam://rungameid/<appid>`.
- **Чего НЕТ в дампе:** имя процесса игры (для закрытия по концу сессии) —
  при дампе бежала только Dota 2 (`dota2.exe`). Снимается вторым заходом за ПК.
- Обложки из старой оболочки (SENET) не забраны — берём ссылки или загрузку.
