Разбор дампа `recon.zip` (машинный PowerShell-сбор за ПК **PC102** пилотного
клуба). Закрывает `docs/РАЗВЕДКА-ШАГИ.md` и `docs/РАЗВЕДКА-У-ПК.md`; отвечает на
часть `docs/АУДИТ-ИГРЫ-NAS.md`. Ниже — что подтвердилось, что оказалось иначе,

## Короткий вывод (TL;DR)

1. **Кого заменяем — опознан: Enestech SENET** (клубная CRM+оболочка). Раньше
   знали только «TrueNAS-раздача» — это было про хранилище, а система
   управления = SENET. Витрина SENET на фото — наш эталон UX для `shell.html`.
2. **Игры запускаются с ЛОКАЛЬНОГО диска D:** (6.6 ТБ, ~1.5 ТБ игр). Не с сети,
   не iSCSI, не diskless. Сетевая шара `\\192.168.123.97\share` (Z:) —
   **отсоединена**, это мастер/источник обновлений на отдельной подсети, а не
   путь запуска. → **Нашему агенту монтировать сеть ДЛЯ ЗАПУСКА не нужно.**
3. **Заморозки (Deep Freeze и пр.) НЕТ.** Только AOMEI Backupper (образы). →
   Наш агент и правки переживут перезагрузку без борьбы с write-filter.
4. **Выход на рабочий стол есть**: аккаунт персонала `pc102\support` —
   локальный админ с полным рабочим столом. → Агент ставить свободно.
5. **Чужая удалёнка подтверждена и на игровых ПК**: MeshCentral, RustDesk,
   Hiddify-туннель, Zabbix — поставлены не клубом. → Это гейт безопасности
   перед переездом, не только «сервер».
6. **Пароля к серверу игр на ПК нет.** → Пароль к `192.168.123.97` берём у
   настройщиков или сбросом на сервере — по-прежнему главный гейт переезда.

## Что подтвердилось по задачам разведки

**Стопор №0 — выход на рабочий стол.** Есть. `whoami`: `pc102\support`,
локальный **администратор**. В момент дампа живьём работали `explorer.exe`,
`powershell.exe`, Steam и Dota 2 — то есть полноценный рабочий стол и админ у
аккаунта персонала. Сам факт машинного сбора это доказывает. Гостевой сеанс
SENET запирается отдельно — это другой режим, не аккаунт `support`.

**Задача 2 — старый софт / заморозка / diskless.**
Инкумбент = **Enestech SENET**: Enestech Bundle 17.3.6.10, Enestech Client
17.3.8.0, SENET Installer 16.0.3.0; службы `clubnetsvc`, `SENET Workstation
Service` (ServiceApp.exe), `SenetInstaller`, `SENETRemoteService`; автозапуск
`SenetInstaller.Client.exe -quiet`. Пульт поддержки SENET = **UltraVNC**
(`winvnc`, в составе Enestech RemoteConnector). Заморозки нет; diskless нет.

**Задачи 3–5 — как игры доезжают.**
- SMB (`net use`): `Z: → \\192.168.123.97\share`, статус **Отсоединён**.
- iSCSI (`iscsicpl`): **пусто** (служба MSiSCSI включена, но таргетов нет).
- Диски: `C:` локальный 466 ГБ (система), **`D:` локальный 6.6 ТБ «Games»,
  3.2 ТБ свободно — игры здесь**, `Z:` сетевой (отсоединён).
- **Итог: схема «копия на локальном диске».** Сервер `192.168.123.97` — на
  отдельной подсети `192.168.123.x` (ПК: `192.168.1.102`, шлюз `.1`); шара =
  мастер/обновления, не рантайм.

**Задача 7 — данные запуска для агента.** Сняты **цели лаунчеров** (`target`,
`args`, `dir`) из ярлыков и командных строк процессов (таблица ниже). **Поле
`process` по каждой игре НЕ снято** — при дампе бежала только Dota 2. Это
остаточный пробел: без имени процесса агент не закроет игру по концу сессии.

**Задача 8 — Steam-карта.** Полная: `libraryfolders.vdf` + 35 манифестов,
всё в `D:\online\Steam\steamapps\common`. Даёт `steam://rungameid/<appid>`
и пути пачкой (таблица ниже).

**Задача 10 — сохранённые креды к серверу.** В Диспетчере учётных данных под
`support` — только токены MicrosoftAccount/WindowsLive. **Пароля к
`\\192.168.123.97` нет.** Значит Z: монтируют другим аккаунтом/их агентом.

**Задача 11 — автозапуск и их агент.** Их агент = SENET (см. выше). Скрипта
`net use` для монтирования игрового диска в автозапуске нет — потому что игры
локальные.

**Задача 12 — античиты.** Vanguard (работает), FACEIT AC, BattlEye,
EasyAntiCheat (EOS), EA AntiCheat, GameGuard, AntiCheatExpert. Все игры
локально → конфликта «античит на сетевом пути» нет.

**Задача 14 — железо/сеть/ОС.** MSI MS-7D45, Intel 12-го поколения
(~i5-12400F класс), 32 ГБ RAM, Realtek **2.5GbE**, Windows 11 Pro 26200
(25H2), **рабочая группа WORKGROUP** (не домен).

## Чужая удалёнка и посторонний софт (гейт безопасности)

На каждом ПК несколько независимых каналов доступа/мониторинга, поставленных
**не клубом**. Прежние настройщики видят и могут трогать парк.

| Что | Где / статус | Кто ставил | Действие |
|---|---|---|---|
| **MeshCentral** (Mesh Agent) | `C:\Program Files\Mesh Agent`, **работает** | локальный аккаунт SID …**-1002** (не support …-1003) | инвентаризировать → удалить |
| **RustDesk 1.4.3** | `C:\Program Files\RustDesk`, установлен | — | удалить |
| **Hiddify** (туннель) | `D:\Program Files (x86)\hiddify-next`, служба Auto | — | выяснить назначение → удалить |
| **Zabbix Agent 2 7.4.6** | `C:\Program Files\Zabbix Agent 2`, работает | — | к чьему серверу шлёт → снять |
| UltraVNC | в составе SENET RemoteConnector | Enestech | уйдёт со сносом SENET |
| RDP (TermService) | штатный, Manual | — | закрыть/ограничить |

Плюс образ клонированный и грязный: `C:\Gry` (польск. «игры», CS 1.6),
остаток `C:\Users\User` в ярлыке TLauncher — следы чужого базового образа.
Есть и мусорный софт: TikTok LIVE Studio, BlueStacks, TLauncher (пиратский
Minecraft), Roblox.

**Вывод:** пока эти каналы живы, клуб не владеет своим парком, а миграция
видна прежним настройщикам. Порядок: сначала доступ к серверу и вычистка
удалёнки + ротация локальных админов (-1002/-1003), потом переезд.

## Что это меняет в 1448 (следующие действия)

**Код/архитектура:**
1. **Агент — рантайм локальный.** Подтвердить, что `cmd/agent` запускает игру
   с локального пути/`steam://` и НЕ монтирует сеть для запуска. Пункт
   games-storage «при SMB — монтирование» демотировать до «монтирование только
   для обновления игр».
2. **Сидировать каталог реальными играми.** Собрать импорт-JSON для
   `/admin/catalog` (Импорт JSON, upsert) из таблиц выше: Steam по appid +
   лаунчеры + не-Steam. Готов сгенерировать по формату `docs/КАТАЛОГ-ИГР.md`.
3. **Снять поле `process`.** Отдельный быстрый заход/скрипт: запустить топ-5
   игр по одной и снять точные имена процессов (`cs2.exe`,
   `VALORANT-Win64-Shipping.exe`, `dota2.exe`, …) — иначе агент не закроет
   игру по концу сессии. Для Steam можно опереться на отслеживание Steam.
4. **Паритет витрины с SENET.** Сверить `shell.html` с UX SENET по фото:
   поиск, вкладки-категории, избранное-звёзды, фильтр License/No-licenses,
   News, сорт New first, пагинация, обложки. Зафиксировать пробелы.
5. **Cleanup между гостями.** Сейвы/кэш игр ложатся в профиль на `C:`
   (`%LOCALAPPDATA%`, Documents, Saved Games) — подтвердить, что `cleanup.go`
   их чистит.

**Переезд (гейт, до кода миграции):**
6. Получить пароль к серверу игр `192.168.123.97` (обновления) — у
   настройщиков или сбросом на консоли сервера.
7. Инвентаризировать и вычистить чужую удалёнку (Mesh/RustDesk/Hiddify/Zabbix),
   ротация локальных админов, закрыть RDP.
8. Раскатка без домена (WORKGROUP): агент ставить поштучно/скриптом; т.к.
   заморозки нет — правки постоянны, но и откат только через AOMEI-образ.
