# План переезда клуба на 14:48 — от разведки до запуска

Последовательный план: каждый шаг в порядке выполнения, с зависимостями.
Опирается на `docs/РАЗВЕДКА-РЕЗУЛЬТАТ.md` (дамп 31.08). Правило порядка:
**наша сторона делается тихо и первой; острые действия с сервером и чужой
удалёнкой — только когда наша сторона готова И получен пароль к серверу игр.**

Легенда: 🟢 наша сторона, невидимо · 🟡 нужен заход за ПК (read-only) ·
🔴 с владельцем / трогает их инфраструктуру.

---

## Карта зависимостей (кратко)

```
Фаза 0 (наша сторона) ─┐
                       ├─► Фаза 2 (гейт доступов) ─► Фаза 3 (1 пилот-ПК) ─► Фаза 4 (весь зал)
Фаза 1 (добор развед.)─┘
Фаза 0 · шаг C1 (вопросы владельцу) стартует параллельно с самого начала
```

Фазы 0 и 1 идут параллельно и ни от кого не зависят. Фаза 2 — гейт: без неё
переезд (3–4) начинать нельзя. Внутри Фазы 2 порядок строгий.

## ФАЗА 0 — наша сторона (сейчас, параллельно, невидимо) 🟢

Ничего на клубных ПК не трогаем. Всё в нашем репозитории.

**0.1. Подтвердить рантайм агента = локальный запуск.**
Проверить `cmd/agent`: игра стартует локальным `target`/`steam://`, сеть для
запуска НЕ монтируется. Пункт «при SMB — монтирование» перевести в «только для
обновления игр». *(зависимостей нет)*

**0.2. Черновой импорт-JSON каталога.**
Собрать файл для кнопки «Импорт JSON» в админке из реальных игр дампа: Steam по
appid (`steam://rungameid/<appid>`) + лаунчеры + не-Steam (таблица в
РАЗВЕДКА-РЕЗУЛЬТАТ.md). Поле `process` пока пустое — дозаполним после 1.1.
*(зависит от формата `docs/КАТАЛОГ-ИГР.md` — он у нас есть)*

**0.3. Чек-лист паритета витрины с SENET.**
По фото клиента SENET сверить с нашей `shell.html`: поиск, вкладки-категории,
избранное-звёзды, фильтр **License/No-licenses**, News, сорт, пагинация,
обложки. Зафиксировать пробелы задачами. Отдельно — история лицензий (на ПК
есть ProjectLAN → часть игр под арендными аккаунтами).

**0.4. Проверить cleanup между гостями.**
Убедиться, что `cleanup.go` чистит сейвы/кэш в профиле на `C:`
(`%LOCALAPPDATA%`, Documents, Saved Games). Финализируется после 1.2.

**Параллельно стартует 🔴 C1 (вопросы владельцу)** — см. Фазу 2, но задать их
можно сразу, ответы нужны к Фазе 2.

Выход Фазы 0: агент подтверждён, каталог залит черновиком, список доводок
витрины, cleanup под вопросом добора.

## ФАЗА 1 — добор разведки (быстрый заход за ПК, read-only) 🟡

Один короткий визит закрывает остаток. Так же тихо, как первый: только смотреть
и запускать игры, ничего не ставить/не менять.

**1.1. Имена процессов топ-5 игр** (главное). Запустить по одной, Диспетчер
задач → «Подробности» → «Командная строка»/«Имя»: снять точные имена
(`cs2.exe`, `VALORANT-Win64-Shipping.exe`, `dota2.exe`, …). Без них агент не
закроет игру по концу сессии. → дозаполняет 0.2.

**1.2. Запись на D: и куда идут сейвы/кэш.** Создать/удалить `.txt` на D:
(запись?), после игры глянуть `%LOCALAPPDATA%`/Documents/Saved Games. →
финализирует 0.4.

**1.3. Обложки из SENET** (по возможности). Если найдётся папка с картинками
игр — забрать в наш каталог.

Выход Фазы 1: каталог полный (с `process`), cleanup подтверждён. **Наша
сторона готова к переезду.**

## ФАЗА 2 — гейт доступов и вычистка (с владельцем, ДО переезда) 🔴

Обязательна перед Фазой 3. Внутренний порядок критичен — не переставлять.

**C1. Вопросы владельцу** (заданы ещё в Фазе 0):
- Это тот же пилотный клуб? Совпадает ли хранение (локальный D: + мастер по
  сети) с тем, что он говорил про TrueNAS?
- Чем сейчас обновляются игры на локальный D: (ProjectLAN? вручную? их агент
  с Z:)? **У кого пароль к серверу `192.168.123.97`?**
- Mesh/RustDesk/Hiddify/Zabbix — санкционированы клубом или это прежние
  настройщики? Zabbix шлёт на чей сервер?
- Лицензии: арендные аккаунты (ProjectLAN/RentalGames) или общий клубный Steam?
  Участвует ли клуб в Steam PC Café?

**C2. Получить/сбросить пароль к серверу игр `192.168.123.97` — ПЕРВЫМ.**
Это источник обновлений игр. Забрать у настройщиков или сбросить на физической
консоли сервера. **Пока пароля нет — их удалёнку и софт НЕ трогать** (иначе
потеряем канал обновления игр).

**C3. Инвентаризация чужой удалёнки.** Куда шлют Mesh/Zabbix, под какими
аккаунтами, чьи каналы. Решить с владельцем keep/remove по каждому.

**C4. Вычистка (только после C2).** Снять MeshCentral, RustDesk, Hiddify,
Zabbix; ротация локальных админов (`-1002`/`-1003`); закрыть/ограничить RDP.
→ теперь клуб владеет своим парком.

Выход Фазы 2: клуб контролирует ПК и сервер обновлений; чужие каналы закрыты.

## ФАЗА 3 — переезд одного пилот-ПК 🔴

Только после Фаз 0+1 (готова наша сторона) и Фазы 2 (доступы наши).

**3.1. Свежий образ AOMEI — точка отката** перед любыми изменениями.
**3.2. Поставить наш агент (127.0.0.1:1448) + шелл РЯДОМ с SENET.** Не сносить
SENET сразу. Проверить: запуск игр из нашего каталога, закрытие по концу
сессии, cleanup между гостями, обновление игр с `192.168.123.97`.
**3.3. Обкатать 1 ПК**, сверить с чек-листом паритета (0.3), закрыть пробелы.
**3.4. Снять SENET** (автозапуск `SenetInstaller.Client.exe`, службы Enestech),
наш шелл — в автозапуск/киоск.

Выход Фазы 3: один ПК полностью на 14:48, откат в кармане.
